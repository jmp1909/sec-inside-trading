Today's Insider Buying Signal

A rerunnable snapshot of the same net-dollar-value ranking validated in the backtest (3-month trailing window, see the full report), scraped directly from individual SEC Form 4 filings rather than the lagged quarterly bulk files. That's really the only way to get anything resembling "current" data, since the bulk files run about a quarter behind.

How to read this

This is a point-in-time snapshot, not a live feed. It reflects whatever was true when src/live_signal.py was last run. Rerun it (weekly is a reasonable cadence, matching the reporting lag insiders are legally allowed) and republish this file to refresh it. Past snapshots aren't overwritten: each run is saved separately in data/live/, so a track record builds up over time.
